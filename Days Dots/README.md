# Days Dots

用圆点可视化本年 / 本月的时间进度：已过去的每一天是实心亮点，剩余的日子是暗点。一眼看清「今年 / 这个月已经走到哪了」。

> 移植自 Scriptable 社区的 [Life Dots](https://scriptore.imarkr.com/scriptables/Days%20Dots) 思路，适配 Scripting 的 `widget.tsx` + `index.tsx` 体系。

## 功能

- 本年 / 本月两种进度视图
- 小、中、大三种小组件尺寸，各自优化布局
- 深 / 浅色主题自动切换，亮色与暗色下的颜色可分别配置
- 本月视图按日历月排成 7 列，可选每周从**周日**或**周一**开始
- 在 App 内运行即可可视化配置并实时预览
- 小组件参数填 `year` 显示本年剩余、填 `month` 显示本月剩余，优先于 App 内配置

## 使用方法

### 在 App 内配置与预览

直接运行脚本，进入配置页：

- **尺寸**：小 / 中 / 大，切换后实时预览
- **进度类型**：本年 / 本月
- **每周开始日**：仅本月视图生效（周日 / 周一）
- **显示百分比**：标题右侧的百分比数字
- **颜色**：已过去（亮/暗）、剩余（亮/暗）、背景（亮/暗），共 6 项，分别取色
- **恢复默认设置** / **在小组件中预览**

所有改动会自动持久化（真机环境），下次打开或刷新小组件即生效。

### 作为小组件使用

把 Scripting 小组件加到主屏，选择本脚本，在「Parameter」里填：

| 参数 | 效果 |
| --- | --- |
| `year` | 显示**本年**剩余天数（忽略 App 内进度类型设置） |
| `month` | 显示**本月**剩余天数（忽略 App 内进度类型设置） |
| 留空 | 使用 App 内配置的进度类型 |

参数同时兼容裸字符串（`year`）与 JSON 字符串（`"year"`）两种形态。

## 配置项

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `progressType` | `year` | 默认进度类型：`year` / `month` |
| `weekStartsOn` | `0` | 每周开始日：`0`=周日，`1`=周一 |
| `showPercent` | `true` | 是否显示百分比 |
| `active` | 亮 `#FF9500` / 暗 `#FF9F0A` | 已过去圆点颜色 |
| `inactive` | 亮 `#D1D1D6` / 暗 `#3A3A3C` | 剩余圆点颜色 |
| `background` | 亮 `#FFFFFF` / 暗 `#000000` | 背景颜色 |

## 实现说明

- 圆点布局由容器尺寸反推：本月固定 7 列；本年按可用宽高自动选择最佳列数，保证圆点尽量大且不被裁切。
- 颜色按 `Device.colorScheme` 在亮 / 暗之间切换；背景使用 `widgetBackground` 修饰符，在 iOS 18+ 的 accented（着色）模式下自动隐藏，避免被系统强行涂白。
- 存储层优先使用原生的 `Storage` API 持久化配置；在缺少该桥的预览 / 校验环境中降级为内存默认值，保证渲染与预览不崩溃，不影响真机功能。
