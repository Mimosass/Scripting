# 订阅流量监控

最多 4 个订阅的流量监控小组件。灵感来自 Egern 的 Hark 环形版订阅流量监控，移植到 Scripting App。

## 功能

- 最多 4 个订阅，同心圆环展示各订阅剩余比例（外圈到内圈依次对应第 1~4 个订阅）
- 小 / 中 / 大 三档尺寸，外加超大尺寸（含横竖屏变体），以及锁屏圆形 / 矩形 accessory
- 订阅链接自动归一化：直接 `https://` 或编码后的 `https%3A%2F%2F` 均可解析
- 多 UA 轮试：自动尝试常见客户端 User-Agent，以适配不同订阅源
- 自动识别订阅头 `subscription-userinfo` 或节点信息
- 今日用量、近 7 天用量图（仅大号 / 超大号展示）
- 套餐总量可手动填写（订阅源只返回剩余量时用于估算百分比）
- 系统动态色 + 半透明卡片，适配 Light / Dark

## 安装

1. 在 Scripting App 中导入本项目（包含 `script.json`、`shared.tsx`、`index.tsx`、`widget.tsx`、`README.md`）
2. 打开脚本的设置页，添加订阅链接（最多 4 个）
3. 把小组件添加到桌面，选择合适的尺寸即可

## 设置项

| 设置 | 说明 |
| --- | --- |
| 链接 | 订阅地址，支持 `https://` 与编码后的 `https%3A%2F%2F` |
| 名称 | 显示在组件上的订阅名 |
| 每月重置日 | 1-31，留空则不显示重置信息 |
| 套餐总量 (GB) | 订阅源只返回剩余量时用于估算百分比，默认 100 |
| 组件标题 | 多订阅时的总标题，留空显示「订阅流量」 |
| 刷新间隔 | 小时，0.5-24，默认 2 |
| 自定义 User-Agent | 留空则自动尝试常见客户端标识 |

## 布局说明

- **小号**：同心环 + 合计剩余 + 今日已用（极简概览）
- **中号**：左侧环 + 右侧各订阅明细卡片
- **大号 / 超大号**：环 + 合计 + 订阅明细卡片 + 近 7 天用量图
- **锁屏 accessory**：圆形显示首个订阅剩余百分比；矩形显示前 3 个订阅的剩余量与到期天数

## 隐私

订阅地址与配置仅保存在本机 Scripting 的 `Storage` 中，不会随脚本分享出去。把脚本分享给他人时，不包含任何个人订阅信息。

## 技术说明

- 圆环、进度条、近 7 天柱状图均使用 `Canvas` 2D 绘制（Scripting 不支持 SVG data URI 图片）
- 卡片使用半透明 `background` + 圆角，预览与桌面渲染一致
- 数据请求失败时回退到上次缓存（标记为「缓存」），无缓存则显示错误
