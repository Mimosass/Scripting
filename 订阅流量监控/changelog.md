# Changelog

本项目所有改动记录于此。当前默认版本：**1.0.0**。

## [1.0.0] - 2026-10-14

- 初始化移植：订阅流量监控小组件（Egern Hark 环形版移植）。
- 支持最多 4 个订阅，编码 URL 与直链均可解析（`normalizeSubUrl`）。
- 多家族适配：小/中/大号及锁屏 accessory（圆形/矩形）。
- 多 UA 轮试拉取订阅信息（clash.meta / clash-verge / v2rayN / Surge / Quantumult X）。
- 流量解析：优先 `subscription-userinfo` 头，回退正文正则（有效期/剩余/总量），base64 兜底节点计数。
- 设置页：订阅链接/名称/重置日/套餐总量、组件标题、刷新间隔（默认 2 小时，0.5–24）、自定义 User-Agent。
- 修复：大号/加大号布局在 ≥3 个订阅时「近 7 天用量」柱形图被隐藏的问题，现始终显示（4 个订阅时高度压缩为 40）。
- 修复：中号无流量订阅（如节点-only）右侧只显示状态词（不再显示「N 节点」），避免与有流量订阅数值混排；节点信息保留在副行。
- 修复：大号/加大号内容超出固定组件高度导致顶部标题与底部星期标签被裁切的问题——收紧上下内边距（14）、合计区环形与字号、周图高度（54/38），并按订阅数自适应；周图例订阅名允许缩字号避免「一分…」截断。
- 布局收尾：大号家族（单/多订阅）进一步自适应并保留边框空白——外框竖向内边距留 10–14pt、压缩合计环（多订阅 56/单订阅 104）、卡片内距与间距，确保内容在 354pt 固定框内不裁切且四周留白；多订阅 4 个时隐藏周图（用 Spacer 占位）优先保证不溢出。
